## Tentang Proyek

FCA Net merupakan aplikasi berbasis web untuk membantu pengelolaan pelanggan WiFi lokal FCA Net di Karangpakis, meliputi data pelanggan, paket internet, tagihan, pembayaran, dan laporan.

## Tanggung Jawab Front-End Developer

Front-End Developer bertugas membuat tampilan aplikasi yang mudah digunakan, menarik, dan responsif, serta menghubungkannya dengan sistem Back-End.

## Tugas Utama (Work Breakdown Structure)

### 1. Analisis Kebutuhan Tampilan
- **Pekerjaan:** Mengidentifikasi kebutuhan halaman dan fitur berdasarkan kebutuhan admin dan pelanggan.
- **Output:** Daftar kebutuhan antarmuka.

### 2. Perancangan UI/UX
- **Pekerjaan:** Merancang tampilan login, dashboard, pelanggan, paket, tagihan, pembayaran, dan laporan.
- **Output:** Rancangan antarmuka aplikasi.

### 3. Pengembangan Halaman
- **Pekerjaan:** Membuat halaman login, dashboard admin, data pelanggan, paket internet, tagihan, pembayaran, dan laporan.
- **Output:** Halaman Front-End aplikasi FCA Net.

### 4. Integrasi Sistem
- **Pekerjaan:** Menghubungkan tampilan dengan API dan data dari Back-End Developer.
- **Output:** Front-End yang terintegrasi dengan Back-End.

### 5. Pengujian dan Perbaikan
- **Pekerjaan:** Memeriksa tampilan, navigasi, formulir, dan fungsi halaman pada komputer maupun ponsel.
- **Output:** Antarmuka yang berjalan dengan baik dan responsif.

## Ruang Lingkup Pekerjaan

Termasuk dalam pekerjaan Front-End Developer:

- Halaman login admin dan pelanggan.
- Dashboard admin dan pelanggan.
- Tampilan data pelanggan, paket, dan tarif.
- Tampilan tagihan dan pembayaran.
- Rekap pembayaran dan laporan bulanan.
- Tampilan pengingat tagihan melalui WhatsApp.
- Navigasi dan desain responsif.
- Integrasi tampilan dengan Back-End.

## Teknologi yang Digunakan

Teknologi Front-End mengikuti kesepakatan tim. Pengembangan dapat menggunakan HTML, CSS, dan JavaScript sesuai rancangan teknis proyek.
