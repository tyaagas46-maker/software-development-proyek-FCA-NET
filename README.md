# software-development-proyek-FCA-NET
#FCA Net
Sistem Informasi Billing dan Administrasi Jaringan Internet berbasis web untuk digitalisasi pengelolaan pelanggan UMKM WiFi lokal FCA Net di Karangpakis.

Proyek mata kuliah Software Development - Teknik Informatika, Universitas Nusantara PGRI Kediri.

#Latar Belakang
FCA Net melayani sekitar 220 pelanggan, tetapi pembayaran (jatuh tempo tanggal 5 dan 21) masih dicatat manual di buku sehingga status lunas atau menunggak sulit dipastikan dan rekap memakan waktu. Aplikasi ini menggantikan pencatatan tersebut dengan sistem digital, tanpa mengubah layanan jaringan.

#Fitur
-Login admin dan pelanggan
-Manajemen pelanggan, paket, dan tarif
-Tagihan bulanan otomatis
-Pencatatan pembayaran (tunai, transfer, sebagian) dan status lunas/kurang bayar/menunggak
-Pengingat tagihan via WhatsApp
-Cek tagihan dan riwayat pembayaran oleh pelanggan
-Dashboard dan laporan bulanan

#Teknologi
Client-Server dengan pola MVC, database MySQL. Backend/frontend: [isi]
