## Tentang Proyek

**FCA Net** adalah aplikasi berbasis web berupa sistem informasi billing dan administrasi jaringan internet untuk digitalisasi pengelolaan pelanggan UMKM WiFi lokal FCA Net di Karangpakis.

Aplikasi ini menggantikan pencatatan pembayaran manual pada buku tulis dengan sistem digital yang membuat tagihan bulanan otomatis, mencatat pembayaran, menandai tunggakan, mengirim pengingat tagihan melalui WhatsApp, dan menghasilkan laporan bulanan.

## Tanggung Jawab Project Manager

Project Manager bertanggung jawab merencanakan, mengoordinasikan, dan memastikan seluruh tahapan proyek berjalan sesuai jadwal, serta menjaga agar pekerjaan Front-End Developer dan Back-End Developer terhubung dengan baik.

## Tugas Utama (Work Breakdown Structure)

### 1. Studi Literatur
- **Pekerjaan:** Mereview artikel jurnal tentang billing RT/RW Net dan digitalisasi pembayaran.
- **Output:** Ringkasan dan analisis jurnal.

### 2. Analisis Kebutuhan
- **Pekerjaan:** Mengobservasi buku catatan pembayaran, mewawancarai pengelola WiFi FCA Net, dan menyusun kebutuhan fungsional serta non-fungsional sistem.
- **Output:** Dokumen analisis kebutuhan.

### 3. Perancangan Sistem
- **Pekerjaan:** Menyusun arsitektur sistem (Client-Server dengan pola MVC) serta alur kerja dari pembuatan tagihan hingga pencatatan pembayaran dan laporan.
- **Output:** Diagram arsitektur sistem.

### 4. Integrasi Sistem
- **Pekerjaan:** Menghubungkan frontend dan backend menjadi satu sistem yang utuh.
- **Output:** Sistem terintegrasi.

### 5. Dokumentasi
- **Pekerjaan:** Menyusun dokumentasi penggunaan dan pengembangan aplikasi, termasuk user manual untuk pengelola.
- **Output:** Dokumentasi proyek.
